# Adaptive storyboard project

Read the toolkit's root CLAUDE.md. This template consumes project.json directly
through default props. Update scenes, titles, onScreenText and asset paths in
that file. Keep asset paths relative to public/. Use the three compositions to
check the same story in landscape, portrait and square. Props files can supply
alternate project data without editing the template code.

Install with npm ci, preview with npm run studio, and render with npm run render,
npm run render:portrait or npm run render:square. Run layout QC on each final
format. Safe-zone guides are for preview and must be disabled in final output.
