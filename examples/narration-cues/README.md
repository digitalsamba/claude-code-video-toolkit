# Narration cues

A runnable synthetic UI demo using the shared `Stage` cursor and camera. Its
clicks follow the named phrases in `cue-spec.json`. Captions supply the timing;
the example renders silently and needs no API key or audio generation.

Generate the cue file from the toolkit root:

```bash
uv run tools/cues.py --captions examples/narration-cues/public/narration.captions.json --spec examples/narration-cues/cue-spec.json --output examples/narration-cues/src/cues.json --fps 30
```

Preview or render:

```bash
cd examples/narration-cues
npm install
npm run studio
npm run render
```

Edit the word timestamps in `public/narration.captions.json`, regenerate cues,
and preview again. The clicks, settings state, and camera move follow the new
times. Keep the three phrases in order and at least 700ms apart so the cursor
has time to travel between buttons. For real narration, replace the sample
captions with the sibling file generated by `tools/captions.py` and play its
audio in the same Remotion Sequence.

`src/Demo.tsx` parses the generated JSON once and calls `cueFrame()` with the
composition's FPS. It uses the resulting frame numbers in cursor paths,
camera keyframes, click ripples, and UI state changes. See
[the cue tool guide](../../docs/narration-cues.md) for repeated phrases, offsets,
and automated checks.
