## How to Get Listed

**Share an example project:**
```
/contribute → Option 5 (Share an example project)
```
Your name/organization and website will be credited in:
- This file
- `examples/README.md`
- Your example's README

**Contribute code or docs:**
Submit a PR and you'll be added to the contributors list.

**Report issues or suggest features:**
Open an issue at [github.com/digitalsamba/agent-video-toolkit/issues](https://github.com/digitalsamba/agent-video-toolkit/issues)
